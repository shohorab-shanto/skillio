Skillio – Online Education & Business Platform (2025 Edition)
Detailed User Stories & Requirements Breakdown

1. Admin Panel Requirements
1.1 Category & Sub-Category Management
User Story:
As an admin, I want to create, edit, and manage categories and sub-categories so that mentors can assign their courses correctly.
Detailed Requirements:
CRUD Operations: Add, edit, delete categories and sub-categories.
Predefined Categories:
Client given categories


1.2 Mentor Verification & Management
User Story:
As an admin, I want to verify mentors and control their availability to ensure only qualified professionals teach on the platform.
Detailed Requirements:
Verification Workflow:
Mentor submits registration → Admin reviews profile (approve/reject).
Availability Toggle:
Admin can mark mentors as "Available" or "Unavailable."
Unavailable mentors won’t appear in search results.


1.3 Course Moderation
User Story:
As an admin, I want to review and approve/reject mentor-submitted courses to maintain quality standards.
Detailed Requirements:
Submission Review:
Mentors submit courses with details (title, description, price, thumbnails).
Admin checks for completeness, plagiarism, and appropriateness.
Publish/Reject Flow:
If approved → Course goes live.
If rejected → Notify mentor with reasons (e.g., "Incomplete materials").
Edits Post-Approval:
Any changes by mentors require re-approval.

1.4 User & Transaction Management
User Story:
As an admin, I want to track users, mentors, transactions, and generate reports for business insights.
Detailed Requirements:
User Management:
View the user list.
Mentor Management:
View the mentor list.
Admin can mark mentors as "Available" or "Unavailable."
Transactions & Commissions:
Automatic 80/20 split (mentor/platform).
Exportable financial reports (daily/weekly/monthly).
Analytics Dashboard:
Enrollments, revenue, top-performing categories/mentors.

2. Mentor Panel Requirements
2.1 Registration & Profile Setup
User Story:
As a mentor, I want to register, get verified, and set up my profile to start offering courses/sessions.
Detailed Requirements:
Registration Flow:
Email/Google/Apple account sign-up → Submit professional details → Await admin approval.
(During Mentor registration no further questionaries are need to be answered just email/google/apple based signup and provide name, phone number, address and awaits for admin approval)
After approval, Profile Management is accessable:
Upload photo, bio, work experience, certifications.
Set working hours & time slots for sessions and prices.
Toggle availability (Online/Offline).

2.2 Course Creation & Management
User Story:
As a mentor, I want to create and manage courses so students can enroll in my programs.
Detailed Requirements:
Course Creation:
Select category/sub-category.
Add title, description, thumbnail, pricing (with discounts).
Set duration (in days)
Admin Review:
Submitted courses go to admin for approval.
Edit & resubmit if rejected.
Post-Publishing:
Track enrollments.
Update content (requires re-approval).

2.3 Session Booking & Earnings
User Story:
As a mentor, I want to manage- in-physical, 1:1 sessions, track bookings, and receive payments.
Detailed Requirements:
Mentoring Time Slots and Fee:
Define available time slots (for online/in-person) and Fee.
Booking Flow:
Students book slots → Payment processed → Confirmation sent.
No rescheduling after payment (just change to another available time slot).
Earnings:
80% of earnings credited to mentor’s account on session bookings.
Notifications:
Instant alerts for new bookings.

2.4 Communication & Reviews
User Story:
As a mentor, I want to communicate with students and receive feedback.
Detailed Requirements:
In-App Chat:
Enabled only during active courses/sessions.
Disabled after completion.
Reviews & Ratings:
Students rate after course/session ends.
Publicly displayed on profile.

3. User Panel Requirements
3.1 Onboarding
User Story:
As a user, I want to sign up easily.
Detailed Requirements:
Sign-Up Options:
Google/Apple/Email login.
Auto-fill name from Google.

3.2 Onboarding Preference-based Recommendation/discovery
User Story:
As a user, I want to complete a quick onboarding questionnaire/discovery process
so that the platform can recommend relevant courses or mentors. 
Detailed Requirements:

Interest Questionnaire:
What type of category/Service are they looking for?
Do they prefer in-person or online education?
If chosen in-person education:
Select Country and City
The system shows the mentors of that specific area under the chosen category/service
If chosen Online Education:
Select Option:
A course from a mentor
If chosen shows all related courses
One-on-one mentoring(Online tutoring)
If chosen shows all related Mentors 
Both combined 
If chosen shows all related courses and mentors

3.3 Course & Mentor Discovery
As a user, I want to browse courses/mentors and filter by my needs.
Detailed Requirements:
Select:
In-Physical Education or Online.
Course Details: 
Title, description, thumbnail, pricing (with discounts).
duration (e.g., "40 days").
Mentor Profiles:
Bio, experience, reviews, testimonial, session prices.
Available time slots

3.3 Enrollment & Payments
User Story:
As a user, I want to enroll in courses/book sessions securely.
Detailed Requirements:
Course Enrollment:
Enter name, email, phone → Pay → Instant access.
In-Physical Education/1:1 Booking:
Select slot → Pay upfront → No changes allowed post-payment.
GDPR consent required.
Payment Methods:
Credit Card, PayPal, Apple Pay.

3.4 Learning & Post-Session Actions
User Story:
As a user, I want to track enrolled courses, chat with mentors, and leave reviews.
Detailed Requirements:
Course Dashboard:
View all enrolled courses, duration left.
Chat System:
Only active during the course/mentoring session.
Reviews:
Rate(course/mentor) after course or mentoring session completion (1-5 stars + comments).

4. System-Wide Requirements
Multi-Language Support: Slovenian, Bosnian, Croatian, Serbian, Macedonian.
Automated Notifications: Booking confirmations, session reminders.
Security & Compliance: GDPR, encrypted payments.
Scalability: Support for future countries/languages.
