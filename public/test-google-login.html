🔑 Google OAuth ID Token Tester

📌 Instructions:
1. Click "Sign in with Google" below
2. Authenticate with your Google account
3. Copy the ID token that appears
4. Use it to test your API endpoint: POST /api/auth/google
⚙️ Configuration Required:
Replace YOUR_GOOGLE_CLIENT_ID in this file with your actual Google OAuth Client ID from the .env file.
